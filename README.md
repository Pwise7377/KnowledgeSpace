Code along theo khóa học "Xây dựng ứng dụng web với ASP.NET Core Web API + Identity Server + Angular" trên TEDU với 2 phần chính:

1. Phần backend bao gồm Web API .NET Core mới nhất kết hợp với Identity Server làm nhiệm vụ chứng thực cho nhiều ứng dụng client khác nhau như Web Portal, ứng dụng SPA Angular, React hay Mobile App.

2. Phần ứng dụng SPA trong khóa này mình sẽ dùng framework rất phổ biến là Angular bản 8 được cải tiến về cấu trúc và cố gắng hoàn thiện chức năng. Mình cũng được học hỏi nhiều từ những developer nước ngoài về dựng structure cho nó nên sẽ có nhiều cải tiến hơn.

Ngoài ra khóa học cũng sẽ đem đến phần Unit test cho phần backend dành cho các bạn. Hy vọng với khóa học này các bạn sẽ hoàn thiện kỹ năng fullstack của mình để chiến các dự án mới với .NET Core và Angular tốt hơn.

# Introduction
KnowledgeSpace is an open source for everyone. Members can create new knowledge base record (KB) and share to community.
For each KB, user can vote and comment below it

# Technology Stack
1. ASP.NET Core 3.1
2. Angular 8
3. Identity Server 4
4. SQL Server 2019

# How to run this Project 
1. Clone this source code from Github with the link (https://github.com/Pwise7377/KnowledgeSpace.git)
2. Build solution to restore all Nuget Packages
3. Set startup project on KnowledgeSpace.BackendServer 
4. Run Update-Database to generate database
5. Set startup project to multiple projects include: KnowledgeSpace.BackendServer and KnowledgeSpace.WebPortal
